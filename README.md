# 跳绳计数器

浏览器端跳绳计数工具：上传视频后，使用 MoveNet 姿态识别追踪髋部和双脚运动并估算跳跃次数。视频帧和分析结果只在当前浏览器内处理。

## 使用

在本目录启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>，上传视频并点击“开始视频分析”。首次分析会从 CDN 加载 TensorFlow.js 和姿态模型，需要联网。

也可以点击“实时播放计数”按视频播放过程计数，或点击“摄像头实时计数”直接使用摄像头。实时模式会先完成模型加载，再开始播放和计数；已经确认的次数只会递增，不会被后续帧撤回。每次结果点击“保存本次记录”，同一视频可以保存多次运行结果。

## 当前边界

- 适合单人、固定机位、全身可见的视频。
- 自动结果是估计值，右侧 `+ / −` 可做最后校正。
- 计数的基本单位是一次完整的上下运动周期：姿态模型给出髋部位置，算法平滑时间序列，在局部最低点确认一次跳跃，并设置最小周期间隔避免重复计数。
- “平衡 / 敏感 / 保守”分别调整动作幅度阈值和最短周期；同一视频可用不同策略比较。
- 下一步可以加入视频内事件标记、导出 CSV、摄像头实时计数，以及把模型文件放到本地实现完全离线。
