# 跳绳计数器

一个在浏览器中使用的跳绳计数工具。选择本地视频进行分析，或通过实时播放、摄像头逐次计数，并把结果记入每日打卡。

[在线使用](https://mentran.github.io/jump-rope-counter/) · [GitHub 项目](https://github.com/Mentran/jump-rope-counter)

## 使用

打开在线页面，选择视频后使用「视频分析」或「实时播放」；也可以打开摄像头。首次计数需要联网加载姿态识别库和模型。实时模式会等模型加载完成后再播放。

结果可手动校正后保存。每日打卡按日期汇总：同一天再次保存同一视频会更新该视频的记录，不同视频分别记录；每次摄像头计数单独记录。

## 计数原理

计数单位是一次完整的身体上下运动周期。系统用双髋位置作为主要信号，双脚可见时加入少量脚部位置，缺少脚部关键点时仍可使用髋部信号。

- **视频分析**：以每秒 15 帧读取完整视频，平滑身体垂直运动信号，寻找满足动作幅度要求的局部低点，并用最短间隔合并重复候选点。
- **实时计数**：模型逐帧识别姿态，在线判断身体下降和回升是否构成完整周期；幅度和最短间隔达标后加 1。已确认的实时次数不会回退。

两种方式各自完成计数，实时播放结束后不会再运行视频分析。算法根据人体姿态估算动作，不识别绳子本身；遮挡、跳跃幅度小、镜头晃动或多人入镜会影响准确度。

## 记录与隐私

打卡记录保存在当前浏览器的 LocalStorage，不会同步到其他设备。每条记录只保存视频标识、时间、计数方式和次数，不保存视频文件或姿态数据。相同视频标识在同一天只保留一条记录，后续保存会更新它。

视频在本地浏览器中处理。页面会从 jsDelivr 加载 TensorFlow.js 和姿态检测库，并向 GitHub API 请求项目 Star 数；视频和计数记录不会发送到这些服务。

## 使用的库

- [TensorFlow.js 4.22.0](https://cdn.jsdelivr.net/npm/@tensorflow/tfjs@4.22.0/dist/tf.min.js)：在浏览器中执行张量计算。
- [Pose Detection 2.1.3](https://cdn.jsdelivr.net/npm/@tensorflow-models/pose-detection@2.1.3/dist/pose-detection.min.js)：提供人体姿态检测接口。
- **MoveNet SinglePose Lightning**：识别单人姿态关键点。

视频读取、画面绘制、摄像头访问、实时调度和本地记录使用浏览器原生 API。项目没有后端服务，也不需要 npm 构建。

## 本地运行

在项目目录启动静态文件服务器：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。首次使用仍需联网加载库和模型。
