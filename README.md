# 跳绳计数器

浏览器端跳绳计数工具：上传视频后，使用 MoveNet 姿态识别追踪髋部和双脚运动并估算跳跃次数。视频帧和分析结果只在当前浏览器内处理。

## 使用

在本目录启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>，上传视频并点击“视频分析”。首次使用会从 CDN 加载 TensorFlow.js 和姿态模型，需要联网。

也可以点击“实时播放”按视频播放过程计数，或点击“摄像头”直接使用摄像头。实时模式会先完成模型加载，再开始播放和计数；每次确认完整起跳就增加 1，下一个周期不会撤回上一个结果。实时播放结束后直接保留在线计数，不会再次分析视频。每次结果点击“保存结果”，同一视频可以保存多次运行结果。

## 当前边界

- 适合单人、固定机位、全身可见的视频。
- 自动结果是估计值，右侧 `+ / −` 可做最后校正。
- 计数的基本单位是一次完整的上下运动周期：姿态模型给出髋部位置，算法平滑时间序列，在局部最低点确认一次跳跃，并设置最小周期间隔避免重复计数。
- 姿态模型逐帧独立推理，关闭了模型内部依赖上一帧的时序平滑；曲线平滑统一放在计数器中，避免实时采样速度改变模型状态。
- 视频分析按固定时间点取样后一次性判断完整序列；实时播放受浏览器和模型推理速度影响，采样间隔会变化。实时模式先采集第 0 秒基准帧，再记录真实视频时间，通过“上升 → 下降”方向变化、动作幅度和最短周期在线确认事件。
- “平衡 / 敏感 / 保守”分别调整动作幅度阈值和最短周期；同一视频可用不同策略比较。
- 下一步可以加入视频内事件标记、导出 CSV，以及把模型文件放到本地实现完全离线。
